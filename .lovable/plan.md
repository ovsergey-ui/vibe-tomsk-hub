
## Что уже есть

- `/admin` — вход для администратора (email + пароль)
- `/_panel/products` — список товаров, добавить/редактировать/удалить (но обложка только URL)
- `/_panel/leads` — список заявок со сменой статуса (Новая / В работе / Закрыта)
- Таблицы `products`, `categories`, `leads`, роль `admin` через `user_roles`

## Что добавляем

### 1. Загрузка изображений с компьютера

- Создаём публичный storage-бакет `product-images` миграцией
- RLS:
  - читать — всем (бакет публичный)
  - загружать/обновлять/удалять — только админу (`has_role(auth.uid(),'admin')`)
- В форме товара (`_panel/products`) добавляем компонент загрузки:
  - drag-and-drop + кнопка «Выбрать файл»
  - превью текущей обложки + кнопка «Удалить»
  - валидация: только image/*, до 5 МБ
  - после загрузки получаем публичный URL и сохраняем в `products.cover_url`
- Поле «URL обложки» оставляем как fallback (свернуть в «Дополнительно»)

### 2. Управление каталогом — улучшения

- Кнопка показать/скрыть товар прямо в таблице (тоггл `is_active` без открытия формы)
- Поиск по названию + фильтр по категории и статусу
- Управление категориями: новый раздел `/_panel/categories` (список + добавить/переименовать/удалить с проверкой связанных товаров)
- Авто-генерация `slug` из названия при создании (с возможностью ручного редактирования)
- Сортировка списка (по дате / названию / цене)

### 3. Заявки — расширенный просмотр

- Раздел «Заказы/Заявки» уже есть, дополняем:
  - бейдж количества новых заявок в навигации
  - фильтр по статусу + поиск (имя/телеграм/email)
  - модалка с полной карточкой заявки (вся информация, ссылка на товар)
  - копирование контактов в буфер
  - период (сегодня / 7 дней / 30 дней / всё)

### 4. Навигация админки

- В `_panel.tsx` добавить ссылку «Категории» рядом с «Решения» и «Заявки»
- Бейдж новых заявок в шапке

## Технические детали

- Storage-бакет создаём миграцией:
  ```sql
  insert into storage.buckets (id, name, public)
  values ('product-images','product-images', true);
  -- policies на storage.objects: SELECT всем, INSERT/UPDATE/DELETE только admin
  ```
- Загрузка из браузера через `supabase.storage.from('product-images').upload(...)` (RLS пускает по сессии админа)
- Имя файла: `${crypto.randomUUID()}.${ext}` в папке `products/`
- При удалении обложки/товара — удаляем файл из бакета
- Список заявок: добавить индекс по `status` и `created_at` если нужен (опционально)
